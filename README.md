# 📚 Личный дневник

Streamlit-приложение для личного дневника: предметы, оценки, долги, время, события и статистика.

## Запуск

```bash
pip install -r requirements.txt
streamlit run app.py
```

При первом запуске приложение попросит создать администратора.

## Важно

Файл `study.db` содержит личные данные и пароли (пароли хранятся в виде хешей). Не добавляй базу данных в публичный GitHub-репозиторий.

Для существующей базы старой версии приложение умеет проверить старые plaintext-пароли и автоматически заменить пароль на защищённый хеш после успешного входа.
